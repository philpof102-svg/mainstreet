Integrate

Score any onchain agent by its Base address. Reads are free:

GET https://avisradar.app/api/agent/score/0x<address>

Or get a yes/no decision in one call — returns a verdict, a score, and a signed attestation:

POST https://avisradar.app/api/agent/check
{ "address": "0x..." }

→ { "verdict": "CAUTION", "score": 50, "attestation": { ... } }

Every check resolves to SAFE, CAUTION, or BLOCK. Wire that straight into your agent's payment guard.

SDK — gate a payment in 3 lines

The mainstreet-oracle package ships a drop-in verifier. Fetch a signed attestation, check the threshold, refuse to pay if it fails or is stale: 

import { requireMinScore } from 'mainstreet-oracle/verifier';
import * as viem from 'viem';

// throws if score < 60, signature invalid, or attestation > 24h old
const score = await requireMinScore(counterparty, 60, viem);
await pay(counterparty);  // only runs if the gate passed

Lower-level helpers are exported too: fetchAttestation, verifyAttestation, and buildOnchainCall for the on-chain path.

Don't trust us — verify the verdict

Every attestation is an EIP-712 typed-data signature from the MainStreet operator (0xAC3ca7c5d3cDD7702fd08F9C4C28dAA22296aDa9), domain { name: "MainStreet", version: "1", chainId: 8453 }. You can recover the signer yourself with viem, no MainStreet code involved: 

const recovered = await viem.recoverTypedDataAddress({
  domain:      att.eip712.domain,
  types:       att.eip712.types,
  primaryType: 'Attestation',
  message:     att.payload,
  signature:   att.signature,
});
// recovered === 0xAC3ca7...aDa9  → the verdict is authentic

Or enforce it on-chain. The MainStreetVerifier contract at 0x7397adb9713934c36d22aa54b4dbbcd70263592b (Base mainnet) exposes requireMinScore(...), so a smart contract can refuse to release escrow unless a fresh signed score clears your bar. MainStreet itself is ERC-8004 registered as agent #53953.

Use it from Claude — 19 MCP tools

MainStreet is an MCP server. Add it once and your agent can score, compare, vet, and preflight counterparties conversationally: 

claude mcp add mainstreet -- npx -y mainstreet-oracle mcp

That exposes 19 tools, including mainstreet_score, mainstreet_check-style mainstreet_preflight, mainstreet_compare, mainstreet_leaderboard, mainstreet_attestation, and mainstreet_verify.

Who this is for

Orchestrator agents routing paid work to providers want a cheap, machine-readable trust signal before forwarding USDC. Buyer agents vetting an unfamiliar counterparty want a one-call SAFE / CAUTION / BLOCK. Escrow and settlement contracts want an on-chain gate that won't release funds to a low-reputation address. One signed score serves all three.

What we're not claiming

We'd rather under-promise. Today there are no on-chain EAS attestations published yet, no Basenames proofs surfaced, and no third-party ERC-8004 agents indexed beyond MainStreet's own registration. Those collectors exist in the repo but currently return zero, so we don't count them. When they produce live data, the numbers on this page will move — and you'll be able to verify every one of them through the public endpoints above.
